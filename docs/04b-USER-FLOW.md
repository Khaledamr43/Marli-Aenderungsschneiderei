# Step 4b — User Flow
_Marli Änderungsschneiderei & Second-Hand · one-page portfolio site_

Visualized on the [FigJam board](https://www.figma.com/board/25ptTuYTufqCqzFFacyNWD) (section "Step 4b · User flow").

## Entry points (how visitors arrive)
- Google search: "Schneiderei Kolbermoor", "Hose kürzen Rosenheim", "Second Hand Kolbermoor"
- Google Maps / Business profile (website link on the listing)
- Instagram or word of mouth

All entries land on the **Hero**, which must answer "what is this and where?" in ~3 seconds.

## The three visitor intents
1. **Needs an alteration** → scans "What we do" → checks the **work gallery** for proof of quality → "Find us" for hours/address
2. **Hunting secondhand** → "Secondhand corner" → "Find us"
3. **Just curious** (heard about the shop) → "About Marli" story → gallery

## Offline outcomes (no CTAs on the site)
The page converts passively — visitors self-serve the info and act outside the site:
- Tap the phone number (mobile) → call → visit
- Open the route in Google Maps → visit
- Follow on Instagram (dotted path — stays in touch, visits later)

**Success = a shop visit or call.** The gallery is the persuasion point ("convinced by the work" is the critical path, drawn thick); "Find us" is the exit hub.

## Design implications (for wireframes, Step 5)
- Gallery and Find-us must be reachable within one swipe/scroll of any intent path
- Phone number rendered as tel: link (passive info, not a styled CTA button)
- Hero must disambiguate the dual identity (alterations + secondhand) immediately, so the decision point works
